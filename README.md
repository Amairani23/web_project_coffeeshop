# Triple Espresso

Esta página web fue desarrollada con **fines educativos**, es un proyecto sobre una pequeña cafeteria que se encuentra dentro de una librería ficticia, por lo que solo contiene lo esencial, como una sección de recetas y un formulario para reservar una mesa.

Contiene:

- Cabecera: logo, titulo, enlaces, información adicional.
- Sección de recetas: titulo, texto, videos (YouTube).
- Formulario de reservación: formulario
- Pie de página: logo, enlaces a redes sociales.

[![imagen de la página ](image/page-coffeeshop.jpg "imagen de la página ")](image/page-coffeeshop.jpg "imagen de la página ")

> - **Nota:** Por ahora solo es la estructura de visualización, no tiene funcionalidad el formulario.
